# 01 — Data Collection

## Overview

This directory contains tutorials available in both English and French.

These tutorials provide instructions for using existing Google Colab notebooks and free software tools to collect and process CMC multimedia data.

**Note:** Other data collection and processing methods developed subsequently during the construction of the Sens-Ex corpus are not covered by these tutorials. They are documented in the [`03_data_preparation/`](../03_data_preparation/) directory.

## Usage

1. Consult the relevant tutorial in [`tutorials/`](tutorials/).
2. Follow the instructions corresponding to the platform and type of data being collected.
3. Verify that the required software and external tools are available.
4. Preserve the original source information and associated identifiers for subsequent corpus processing.

## Limitations

These resources were developed for the specific requirements of the Sens-Ex corpus and may require adaptation to other research contexts.

Users are responsible for verifying applicable platform conditions, data protection requirements, and permissions before collecting or redistributing data.
