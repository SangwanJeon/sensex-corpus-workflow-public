# Automatic and Revised Annotation Samples

This directory stores the automatic CoNLL-U baseline and exported annotation revisions for Sens-Ex.

## Directory Structure

```text
samples/
├── README.md
├── auto/
├── annotator_revision_1/
└── annotator_revision_2/
```

| Directory | Contents |
| --- | --- |
| [`auto/`](auto/README.md) | Automatic CoNLL-U files before manual revision, retained as the baseline. |
| [`annotator_revision_1/`](annotator_revision_1/README.md) | CoNLL-U files exported from ArboratorGrew for annotation revision 1. |
| [`annotator_revision_2/`](annotator_revision_2/README.md) | CoNLL-U files exported from ArboratorGrew for annotation revision 2. |
