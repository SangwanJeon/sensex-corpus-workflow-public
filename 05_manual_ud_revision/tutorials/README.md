# Tutorials

The tutorial for this stage is currently available in French. It introduces automatic morphosyntactic and syntactic processing and the subsequent manual annotation workflow in ArboratorGrew.

## Topics Covered

- Automatic morphosyntactic annotation and dependency parsing, in connection with [stage 04](../../04_automatic_morphosyntactic_nlp/).
- Importing CoNLL-U files into [ArboratorGrew](https://arborator.grew.fr/).
- Inspecting and manually correcting linguistic annotations and dependency structures.
- Exporting corrected CoNLL-U files into the [sample revision directories](../samples/README.md).
- Trying a [SUD](https://surfacesyntacticud.org/) proposal for encoding coconstructions.

The coconstruction encoding is experimental and remains a proposal under exploration.
